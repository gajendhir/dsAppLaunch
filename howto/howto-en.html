1. What it does

dsAppLaunch shows the programs you use every day as a grid of cards. Click ▶ Launch on a card to start that program. Tick several cards and click ▶ Launch Selected to start them all in one go — handy for the set of programs you open at the start of every working day.

You do not need any technical knowledge. If you can pick a file in a folder window, you can set this up.

2. Your first start

The first time dsAppLaunch opens, it shows a Getting Started group with two cards — this guide in English and in Hindi. Click ▶ Launch on either card to open the guide in your web browser, any time you need it.

Tip: once you have added your own programs you can remove these two cards (see section 4). To bring them back later, close the launcher, delete the settings file described in section 8, and start the launcher again.

3. A tour of the main window

  1. Reload (circular arrow) — re-reads your list and clears temporary ticks.
  2. Manager (gear) — opens the window where you add and edit programs.
  3. Tick box — select this card for Launch Selected. Ticked cards get an orange outline.
  4. Launch — start just this program.
  5. Small gear — open the Manager with this program already selected.
  6. Launch Selected (n) — start every ticked card; n is how many are ticked. It is grey until you tick at least one.
  7. All — tick every card.
  8. None — clear every tick.

4. Add your own programs

Click the gear at the top right to open the Manager.

Two ways to add a program

  1. Drag and drop — drag a program (an .exe file or a shortcut) from Windows Explorer onto the list. One entry is created for every file you drop. You can also drop a file onto the Executable or Custom Icon boxes to fill them in.
  2. Add New — click + Add New, type a name, click Browse... next to Executable Path and choose the program.

When you are finished, click Save & Apply Changes. The Manager closes and your cards appear on the main screen. To delete a program, select it in the list and click - Remove.

What each field does

  1. Configured Applications — every program you have added. Click one to edit it.
  2. + Add New — create a blank entry.
  3. - Remove — delete the selected entry.
  4. Application Name — the title shown on the card.
  5. Executable (.exe) Path — the program to start. A document or web-page file (such as .pdf or .html) also works A web page or document also works — Windows opens it with its usual program.mdash; Windows opens it with its usual program.
  6. Browse... — find the program in a folder window.
  7. Custom Icon Path (optional) — a picture or icon to show instead of the program’s own icon.
  8. Group (optional) — cards with the same group sit together under one heading, such as Office or Accounts.
  9. Sub Group (optional) — a second label shown on the card, such as a year or a branch.
  10. Category — a short label such as Utilities, shown in brackets on the card.
  11. Pick Color... — colour-code the card (see section 5).
  12. Description — a short note shown on the card.
  13. Sort Order (lower first) — position of the card within its group. 1 comes before 2, and so on.
  14. Include in ‘Launch Selected’ by default — tick this for programs that should already be ticked every time you open the launcher.
  15. Save & Apply Changes — save everything and return to the main window.

Network programs: if a program lives on a shared network drive (a path starting with \\), it works on any computer that can reach the same drive.

5. Group, order and colour

  • Groups. Give related programs the same Group text. They appear together under a heading. Programs with no group are listed under (Ungrouped).
  • Order. Within a group the cards follow Sort Order — lowest number first. This is also the order in which Launch Selected starts them, so put the program that must open first at number 1.
  • Colour. Click Pick Color... to colour-code a card. The colour appears as a stripe along the card’s left edge and a soft tint. Leave it white for a plain card.
  • Daily set. Tick Include in ‘Launch Selected’ by default for the programs you start every morning. Then one click on ▶ Launch Selected opens them all.

6. Launch one or many

  • One program: click ▶ Launch on its card. The card shows a short “starting” state while Windows opens the program.
  • Several programs: tick the box at the top right of each card you want, then click ▶ Launch Selected (n). The programs start one after another, about a second apart, in the order they appear on screen.

Ticks last for the current session. If you click Reload, or save in the Manager, the ticks return to whatever you chose with Include in ‘Launch Selected’ by default.

If a program cannot be started — for example the file was moved, or a network drive is not connected — you get one message at the end listing only those programs. The others still start.

7. What is on a card

  1. Icon — the program’s own icon, or your custom icon.
  2. Name — the Application Name.
  3. Sub Group — the second label.
  4. Modified — when the program file was last changed. Double-click it to open the folder that contains the program.
  5. [Category] Description — your own notes.
  6. Tick box — select for Launch Selected.
  7. Launch — start this program.
  8. Gear — edit this program in the Manager.

Cards for programs on a network drive appear straight away; the icon and date fill in a moment later. If the drive is switched off, that card simply stays plain — the rest of the launcher keeps working.

8. Where your list is stored

Your list of programs is saved in one file:

%AppData%\Data Spec\dsAppLaunch\apps.json

To open the folder, press Windows + R, paste %AppData%\Data Spec\dsAppLaunch and press Enter.

  • Back up or move to another computer: copy apps.json.
  • Start fresh (and see the first-start guide cards again): close the launcher, delete apps.json, and start it again.
  • Updating or uninstalling dsAppLaunch does not remove this file, so your list survives a reinstall.

9. If something goes wrong

ProblemWhat to do
A card says the program was not foundThe file was moved or deleted, or the network drive is not connected. Open the Manager, select the program and check the Executable Path.
The Manager will not open and mentions apps.jsonThe settings file was damaged, usually by a manual edit. Fix the text the message points to, or delete the file and add your programs again.
A card has no icon or dateThe program’s file cannot be reached (yet). Wait a few seconds, or click Reload.
I changed something outside the launcher and it is not showingClick Reload.
The guide cards do not openThe guide files live in the howto folder next to the program. If you moved or deleted that folder, reinstall dsAppLaunch or remove the two cards.
