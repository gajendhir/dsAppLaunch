## Description (en-us)
Data Spec App Launcher puts your everyday programs on one clean screen. Add the programs you use,
group them, colour-code the cards, and start any of them with a single click, or tick several and
start them all together.

Features
• Card grid with each program's own icon, name, description and last-modified date
• Groups with headings, and a sort order inside each group
• Launch Selected: tick several cards and start them one after another, in on-screen order
• Colour-code cards with a stripe and soft tint, or pick a custom icon
• Built-in settings dialog: add, edit and remove entries, browse for files or drag and drop them in
• Fast start: file checks and icon loading happen in the background, so slow network drives never freeze the window
• Plain, human-readable JSON settings stored per user. No account, no ads, no data collection
• Works with high-DPI and multi-monitor setups

A short how-to guide (English and Hindi) is included and opens from the first cards you see.

## Notes for certification (paste in)
This app is a launcher for the user's own desktop programs, so it declares the restricted capability
runFullTrust (Win32 desktop app packaged with MSIX). It does not use the network, sign-in or
background services.

How to test: start the app. The first run shows a "Getting Started" group with two how-to cards that
open the bundled guides. Click the gear button (top right), choose + Add, browse to
C:\Windows\System32\notepad.exe, give it a name and click Save & Apply Changes. A Notepad card
appears; click Launch, or tick cards and click Launch Selected. No account or credentials are needed.

## runFullTrust justification
Launcher that starts the user's own installed desktop applications; it must run as a full-trust
desktop process to start other Win32 programs and read their icons.
